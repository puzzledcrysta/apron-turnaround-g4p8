# 机坪周转核算

面向机场运行结算员。按分钟计算保障占用，合并多个豁免区间的交集，再按 15 分钟进位计费。复算后按保障单核对独立清单，查看单据证据和差值，再登记复核结论。

## 启动

```sh
docker compose up --build
```

默认访问 http://localhost:18280。
打开工作台，点击运行即可使用内置的班次样例。选择导入可以换成自己的来源与独立账 CSV。
样例在 `sample_data/`，`shift.csv` 有分页表头、冲突修订、坏行、空值哨兵与业务拒绝，`external.csv` 有单边与数值差异。
端口可通过 `APP_PORT` 覆盖。运行记录和复核历史保存在 `ledger` 卷。

## 操作

- 在区间计费展开业务证据，核对原始字段与计算项。
- 在隔离裁决逐行检查原因。独立对账按键对比外部账并列出差值。
- 在批次复算重跑当前输入。在交付复核提交带版本意见，并导出证据包。
- 在关账调整对已确认批次登记晚到高修订：预览计费分钟与外部账差异变化，逐单选择纳入本次或留待下期，生成并导出新结算结果；原确认账单保持只读，同一修订重跑不重复累计。
